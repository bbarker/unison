# Performance Baselines

This directory stores golden performance summaries generated by:

```bash
scripts/unison/reference-perf.sh --profile <profile> --update-baseline
```

Expected layout:

- `<profile>/summary.tsv`
- `<profile>/cases.txt`
- `<profile>/samples/<case>.samples.tsv`

Notes:

- Baselines use repeated samples with confidence intervals (`ci95_ms`).
- Regression checks compare means with error bars and a configurable percent threshold.
- Keep correctness checks (`reference-corpus.sh`) and performance checks (`reference-perf.sh`) separate.
